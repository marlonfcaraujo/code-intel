## Code Intel

Use code-intel for self-contained repository-aware navigation before non-trivial code changes.
Prefer the MCP server tools when configured: `catalog_health`, `catalog_repo`, `workspace_catalog`, `list_workspaces`, `workspace_lookup`, `workspace_references`, `workspace_context`, `workspace_context_many`, `workflow_benchmark`, `context_pack`, `lookup`, `find_symbols`, `find_references`, `search_text`, `get_file_outline`, `get_file_content`, `get_file_tree`, `repo_outline`, `workspace_outline`, `explain_file`, `related_tests`, `risk_report`, and `savings_report`.
CLI fallback: refresh with `uv run --project /path/to/code-intel code-intel scan . --incremental --json`, then use `uv run --project /path/to/code-intel code-intel lookup --repo . query`, `uv run --project /path/to/code-intel code-intel workspace-lookup --workspace name query --source-first`, `uv run --project /path/to/code-intel code-intel lookup --repo . KnownSymbol --source-first`, `uv run --project /path/to/code-intel code-intel references --repo . SymbolName`, `uv run --project /path/to/code-intel code-intel workspace-references --workspace name SymbolName`, `uv run --project /path/to/code-intel code-intel workspace-context --workspace name query --source-first`, `uv run --project /path/to/code-intel code-intel workflow-benchmark --workspace name --query query --source-first --json --summary`, `uv run --project /path/to/code-intel code-intel tree --repo .`, `uv run --project /path/to/code-intel code-intel repo-outline --repo .`, `uv run --project /path/to/code-intel code-intel workspace-outline --workspace name`, `uv run --project /path/to/code-intel code-intel explain --repo . path/to/file.py`, `uv run --project /path/to/code-intel code-intel find --repo . SymbolName`, or `uv run --project /path/to/code-intel code-intel search-text --repo . query`; save repeated backend/UI sets with `uv run --project /path/to/code-intel code-intel workspace-save name --repo backend --repo ui/src` and refresh them with `uv run --project /path/to/code-intel code-intel workspace-scan --workspace name --incremental --json`; use `uv run --project /path/to/code-intel code-intel outline --repo . path/to/file.py` before reading source; check catalog freshness with `uv run --project /path/to/code-intel code-intel doctor . --summary` and impact with `uv run --project /path/to/code-intel code-intel savings --repo .`.
Use `uv run --project /path/to/code-intel code-intel install-refresh-job ...` on macOS when a repo needs scheduled incremental indexing.
The generated catalog is `.code-intel/catalog.sqlite`; do not commit it.

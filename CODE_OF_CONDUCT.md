# Code of Conduct

This project expects professional, respectful collaboration.

## Expected Behavior

- Be direct and constructive.
- Focus critique on code, behavior, and tradeoffs.
- Assume maintainers and contributors are trying to improve the project.
- Respect different levels of experience and different working contexts.

## Unacceptable Behavior

- Harassment, threats, or personal attacks.
- Discriminatory language or conduct.
- Publishing private information without permission.
- Repeated disruption after maintainers ask for a change in behavior.

## Enforcement

Maintainers may edit, hide, or remove comments; close issues or pull requests;
or block participants when conduct makes collaboration unsafe or unproductive.
Report concerns through the project's security or maintainer contact paths.

# Roadmap

This document tracks planned work for `code-intel` and helps contributors align with
current priorities.

## Current focus

- Improve workspace-scanning ergonomics for mixed-language monorepos
- Add clearer diagnostics for scan refresh failures
- Expand benchmark outputs for CI and long-running repository indexes
- Improve agent-friendly docs for setup across macOS/Linux environments

## Planned improvements

- Publish optional language plugins for additional non-Python stacks
- Provide a lightweight compatibility report for MCP consumers
- Add more guided templates for high-signal bug reports

## Completed

- Local SQLite catalog format and scan/index lifecycle
- Core symbol lookup and reference traversal commands
- Workspace save/scan/context command flow
- GitHub issue templates and contributor documentation

## How to contribute to roadmap items

Open an issue or discussion to propose additions and include:

- why the item is important
- expected impact on day-to-day agent workflows
- any compatibility risks
- a small implementation sketch if you can
